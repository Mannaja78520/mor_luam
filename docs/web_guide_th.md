# คู่มือเว็บของหุ่น mor_luam (ภาษาไทย)

เว็บนี้อยู่ในตัวหุ่น (ESP32) ไม่ต้องลงโปรแกรมอะไร ไม่ต้องใช้เน็ต และไม่ต้องเปิด ROS

## 1. วิธีเปิดเว็บ

**ง่ายที่สุด:** บนคอมพิมพ์ `docker\mor_luam.bat web` (Ubuntu: `./docker/mor_luam.sh web`)
คำสั่งนี้หาหุ่นให้ บอกที่อยู่สำหรับคอมและมือถือ บอกว่าต้องต่อ WiFi วงไหน แล้วเปิดเบราว์เซอร์ให้เลย

### แบบปกติ: ผ่าน WiFi `manny` (hotspot ของคอม)
1. เปิด Mobile Hotspot ของคอม (ชื่อ `manny`)
2. เปิดหุ่น รอประมาณ 10–20 วินาที
3. ใช้คอม หรือมือถือที่ต่อ WiFi `manny` เปิดเบราว์เซอร์ แล้วพิมพ์
   ```
   http://mor-luam.local
   ```
4. ถ้าเปิดไม่ขึ้น (มือถือ Android บางรุ่นไม่รู้จักชื่อ `.local`) ให้หา IP ของหุ่นจากคอม
   ```
   docker\mor_luam.bat find
   ```
   แล้วเปิด `http://<IP>/` เช่น `http://192.168.137.212/`
   **IP เปลี่ยนได้ทุกครั้งที่หุ่นต่อ WiFi ใหม่** ให้ใช้ `find` ทุกครั้งที่ไม่แน่ใจ

### แบบไม่มี WiFi: ผ่าน hotspot ของหุ่นเอง
ถ้าหุ่นหา WiFi ที่บันทึกไว้ไม่เจอเกิน 20 วินาที หุ่นจะปล่อย WiFi ชื่อ `mor-luam-XXXX` เอง
1. ต่อ WiFi `mor-luam-XXXX` (รหัส = รหัส hotspot ในแท็บตั้งค่า ค่าเริ่มต้นอยู่ใน `firmware/config/`)
2. เปิด `http://192.168.4.1`
3. ไปแท็บ WiFi เพิ่ม WiFi ที่ใช้จริง แล้วหุ่นจะไปต่อวงนั้นเอง

### แบบไม่มีหุ่น: หุ่นจำลองบนคอม (ไว้ลองเว็บ / แก้หน้าเว็บ)
```
docker\mor_luam.bat web-mock
```
แล้วเปิด `http://localhost:8000` (ข้อมูลทั้งหมดเป็นของปลอม หุ่นจริงไม่ขยับ)

## 2. แถบด้านบน (เห็นทุกแท็บ)
| ส่วน | ความหมาย |
|---|---|
| ชื่อหุ่น + บรรทัดสถานะ | หุ่นกำลังทำอะไร หรือหยุดเพราะอะไร |
| `หุ่น` | สด = ข้อมูลล่าสุด · ช้า = ข้อมูลค้าง · หลุด = ติดต่อหุ่นไม่ได้ |
| `WiFi` | ความแรงสัญญาณ (dBm) หรือ hotspot |
| `ROS` | ต่อแล้ว / รอ agent (ใช้เฉพาะเมื่อสั่งจากโปรแกรม ROS) |
| ปุ่มแดง **หยุด (E-STOP)** | หยุดล้อและเส้นทางทันที กดได้ทุกเมื่อ |

ถ้ามีแถบแดง "ติดต่อหุ่นไม่ได้" = ตัวเลขที่เห็นเป็นค่าเก่า หน้าเว็บจะต่อใหม่เอง

## 3. แท็บ "เส้นทาง" (วางจุดบนระนาบ 2 มิติ แล้วให้หุ่นวิ่งจริง)
- **ระนาบ:** หน่วยเมตร (0,0) = จุดที่ตั้งไว้ล่าสุด แกน +x = ทิศที่หุ่นหันตอนนั้น แกน +y = ทางซ้ายของหุ่น
  ลูกศรขาว = ตัวหุ่น · เส้นเขียว = ทิศล้อ · เส้นประส้ม = ขาที่กำลังวิ่ง
- **วางจุด:** แตะที่ว่างบนระนาบ · **ย้ายจุด:** ลากจุด · **ลบจุด:** กดปุ่ม "ลบจุด" แล้วแตะจุด
- **ล็อกตาราง 0.1 m:** จุดใหม่จะลงตารางทุก 10 ซม. · **ตามหุ่น / พอดีจอ / ล้างรอยทาง:** ช่วยดูภาพ
- เลื่อนภาพ: ลากที่ว่าง · ซูม: ล้อเมาส์ หรือใช้สองนิ้ว
- **ตารางจุด:** แก้ค่า x, y เป็นตัวเลขได้ ↑ = เลื่อนลำดับ ✕ = ลบ
  "บันทึกลงหุ่น" = ส่งจุดเข้าหุ่น · "ใช้ชุดในหุ่น" = ยกเลิกที่แก้ · "ล้างทุกจุด"
- **วิ่งจริง:**
  1. ตรวจว่าหุ่นอยู่บนพื้น พื้นที่ว่าง และคุณอยู่ข้างหุ่น
  2. ติ๊ก "หุ่นอยู่บนพื้น ฉันอยู่ข้างหุ่น และพื้นที่ว่างแล้ว"
  3. กด **เริ่มวิ่งหุ่นจริง** (ถ้ายังไม่ได้บันทึกจุด เว็บจะบันทึกให้ก่อน)
  4. หยุดเองด้วย "หยุดเส้นทาง" หรือ E-STOP
- **ความปลอดภัย:** ระหว่างวิ่ง หน้าเว็บส่งสัญญาณตลอด ถ้าปิดหน้า จอมือถือดับ หรือเน็ตหลุดเกิน 3 วินาที หุ่นตัดไฟมอเตอร์ภายใน 0.01 วินาทีหลังครบ 3 วินาที (วัดจริง 2.97–3.01 วินาที ไม่ไถลต่อ) · หน้าเว็บที่เปิดค้างไว้ที่ไหนก็ตามจะทำให้หุ่นวิ่งต่อได้
- **ตั้งตรงนี้เป็น (0,0):** ใช้ก่อนวางจุดชุดใหม่ (ใช้ได้ตอนหุ่นหยุดเท่านั้น)

## 4. แท็บ "จำลอง" (Detour Steer เทียบ Direct)
### ส่วนจำลอง (ไม่ส่งคำสั่งให้มอเตอร์ หุ่นไม่ขยับ)
1. วางจุดในแท็บเส้นทางก่อน
2. ตั้งความเร็วขับ (ค่าแนะนำ 0.03 m/s) และความเร็วเลี้ยว (60 °/s) — เป็นค่าของการจำลองเท่านั้น
3. กด **จำลองจุดที่วาง** → เห็นสองเส้นพร้อมกัน
   - **เส้นเขียว = แบบที่ 2 Detour** (อ้อม: ขับไปตามล้อก่อน แล้วค่อยเลี้ยว)
   - **เส้นส้ม = แบบที่ 1 Direct** (เลี้ยวล้อตรงไปหาจุด แบบเดิม)
   - ด้านบนบอกเวลาของแต่ละแบบ และต่างกันกี่วินาที
4. "ตัวอย่างอ้อม 0.3 m / 6°" = ตัวอย่างที่ Detour ชนะ (ไม่เปลี่ยนจุดในหุ่น)
5. "พัก" / "เริ่มใหม่" / ความเร็วภาพ 1× 4× 10×
6. ติ๊ก **จำลองความคลาดเคลื่อนและการสั่น** = เพิ่มความผิดพลาดของ IMU / มุมล้อ / การลื่นแบบสุ่ม
   "ชุดตัวเลขสุ่ม (Seed)" เดิม = ได้ผลเดิมทุกครั้ง · "ขยายภาพการสั่น" = ขยายให้มองเห็น (ค่าจำลองโดยประมาณ)

หมายเหตุ: หุ่นจริงวิ่งช้า (~0.03 m/s) Detour จึงชนะเฉพาะจุดที่อยู่เลยล้อไปนิดเดียว (เลี้ยวตรงต้องหมุนเกือบรอบ)

### ส่วน "ทดสอบเคลื่อนที่จริง แบบที่ 1 / แบบที่ 2" (หุ่นขยับจริง)
1. วางจุดในแท็บเส้นทาง
2. ใส่ "มุมล้อเริ่มร่วมกัน" หรือกด "ใช้มุมล้อปัจจุบัน" (ทั้งสองแบบเริ่มจากมุมล้อเดียวกัน)
3. วางหุ่นที่จุดเริ่ม หันทิศเดิม แล้วติ๊กช่องยืนยันว่าพร้อม
4. กด **วิ่งจริง แบบที่ 1 · Direct** — หุ่นตั้งมุมล้อก่อน แล้วจับเวลาจนถึงทุกจุด
5. ยกหุ่นกลับจุดเริ่ม หันทิศเดิม ติ๊กยืนยันอีกครั้ง กด **วิ่งจริง แบบที่ 2 · Detour**
6. ดูเวลาของทั้งสองแบบในกล่องผล ("หยุดทดสอบ" = หยุดทันที ผลนั้นไม่นับ)

## 5. แท็บ "WiFi"
- **การเชื่อมต่อตอนนี้:** ชื่อวง (ลำดับที่) สัญญาณ IP ชื่อในวง hotspot ของหุ่น · "เชื่อมต่อใหม่" = ให้หุ่นต่อใหม่ตามลำดับ
- **WiFi ที่บันทึกไว้ (สูงสุด 6 วง):** ลำดับในรายการ = ลำดับความสำคัญ
  - WiFi หลุด → ต่อวงเดิมก่อน ถ้าไม่เจอ → ไล่วงที่ 1, 2, 3 …
  - ต่อวงลำดับรองอยู่ แล้ววงที่สูงกว่ากลับมา → หุ่นย้ายไปเอง (เช็กทุก 30 วินาที ตอนหุ่นหยุดนิ่ง)
  - ปุ่ม: แสดง/ซ่อนรหัส · แก้ · ↑ เลื่อนขึ้น · ลบ · "แสดงรหัสทั้งหมด"
- **เพิ่ม WiFi:** ใส่ชื่อ (SSID) และรหัส (8–63 ตัว หรือเว้นว่างถ้าไม่มีรหัส) → "บันทึก WiFi"
- **WiFi รอบตัวหุ่น:** กด "สแกน" แล้วแตะชื่อวง (หรือ "ใช้วงนี้") เพื่อเติมชื่อให้
- **คำเตือน:** ทุกคนที่เปิดเว็บหุ่นได้จะเห็นรหัส WiFi ทุกวง ใช้ในวงที่ไว้ใจเท่านั้น

## 6. แท็บ "ตั้งค่า"
- **ตั้งค่าหุ่น** (กด "บันทึกการตั้งค่า" · "ใช้ค่าในหุ่น" = ยกเลิกที่แก้)
  - ชื่อหุ่น · ชื่อในวง mDNS (เปลี่ยนแล้วเปิดเว็บด้วยชื่อใหม่ `.local`)
  - Algorithm: Detour Steer หรือ เลี้ยวตรงไปหาจุด
  - ความเร็ววิ่ง: 0.005–0.035 m/s (เต็มกำลังได้ ~0.039 m/s) · ระยะถึงจุด · ความเร็วเลี้ยวล้อ (ω) · วนเส้นทางซ้ำ
  - ROS agent (เว้นว่าง = หาเอง) · port
  - รหัส OTA · รหัส hotspot ของหุ่น — **ควรเปลี่ยนจากค่าเริ่มต้น**
- **PIDF:** ค่า Kp Ki Kd Kf tol ของล้อขับ (spin) และล้อเลี้ยว (steer) → "ใช้ค่า …" มีผลทันที
  (รีบูตแล้วกลับเป็นค่าใน `firmware/config/PIDF_config.h`)
- ตารางด้านล่าง PID: เวลาไถลของล้อเลี้ยว (เรียนรู้เอง) และ **ตัวคูณกำลังล้อขับ (เรียนรู้เอง)** =
  ระบบปรับกำลังตามแบตที่ลดลงให้อัตโนมัติ (ไม่ต้องตั้งเอง)

## 7. แท็บ "ระบบ"
- **อัปเดตเฟิร์มแวร์ผ่าน WiFi (OTA):** เลือกไฟล์ `firmware\firmware_out\firmware.bin` (ได้จาก `docker\mor_luam.bat fw-build`)
  ใส่รหัส OTA → "อัปโหลดและรีบูต" (หุ่นต้องหยุดอยู่) หรือจากคอม: `docker\mor_luam.bat fw-ota -Host mor-luam.local`
- **หุ่นในวงเดียวกัน:** กด "ค้นหา" เห็นหุ่น/โมดูลตัวอื่น กด "เปิด" เพื่อไปเว็บของตัวนั้น
- **ROS 2** และ **ระบบ:** สถานะ agent, เฟิร์มแวร์, RAM, เวลาเปิดเครื่อง
- "ธีม" สว่าง/มืด/ตามเครื่อง · "รีบูตหุ่น"

## 8. ปัญหาที่เจอบ่อย
| อาการ | แก้ |
|---|---|
| เปิด `mor-luam.local` ไม่ขึ้น | ใช้ `docker\mor_luam.bat find` แล้วเปิดด้วย IP |
| มือถือเปิดไม่ขึ้นแต่คอมเปิดได้ | มือถือต้องต่อ WiFi `manny` และใช้ IP แทน `.local` |
| หาหุ่นไม่เจอเลย | หุ่นอาจเปิด hotspot `mor-luam-XXXX` อยู่ → ต่อวงนั้นแล้วเปิด `http://192.168.4.1` |
| แถบแดง "ติดต่อหุ่นไม่ได้" | หุ่นรีบูต / แบตหมด / หลุด WiFi: รอ หน้าเว็บต่อใหม่เอง |
| ปุ่มวิ่งจริงกดไม่ได้ | ยังไม่ได้ติ๊กช่องยืนยัน หรือยังไม่มีจุด หรือหุ่นยังไม่หยุดนิ่ง |
| หุ่นหยุดเองกลางทาง | ปิดหน้าเว็บ / จอดับ / เน็ตหลุดเกิน 3 วินาที (ตั้งใจให้หยุดเพื่อความปลอดภัย) |
| อัปเดตไม่ได้ | หุ่นกำลังวิ่ง (หยุดก่อน) หรือรหัส OTA ผิด |

คู่มือภาษาอังกฤษแบบละเอียด: `docs/web_ui.md` · คู่มือติดตั้ง/คำสั่งทั้งหมด: `docker/README.md`

## 9. ปุ่มบนหุ่น (GPIO19 ต่อลง GND มี pull-up)

| กด | ทำอะไร |
|---|---|
| 1 ครั้ง | **เดโม 1 = เส้นทาง 1** (ตั้งจุดเองในเว็บ) ค่าเริ่ม: หน้า 1 ม. → ซ้าย 1 ม. → กลับจุดเริ่ม |
| 2 ครั้งติดกัน | **เดโม 2 = เส้นทาง 2** (ตั้งจุดเองในเว็บ) ค่าเริ่ม: หน้า 0.5 ม. → ซ้าย 0.5 ม. → กลับจุดเริ่ม |
| 3 ครั้งติดกัน | **เดโม 3: Direct** (ไม่ลัด) หันล้อไปหน้าหุ่นก่อน แล้วจับเวลาไปเป้า: ห่าง 20 ซม. เยื้องขวาจากล้อ 10° |
| 4 ครั้งติดกัน | **เดโม 4: Detour** (ลัด) เป้าเดียวกับเดโม 3 จับเวลาเหมือนกัน |
| กดระหว่างหุ่นเคลื่อนที่ | **หยุดทันที** (เหมือน E-STOP) |
| กดค้างเกิน 1.5 วินาที | ไม่เริ่มอะไร (ใช้ทดสอบสายปุ่มได้) |

- หุ่นเริ่ม 1 วินาทีหลังการกดครั้งสุดท้าย
- **ตั้งจุดของเส้นทาง 1 / 2:** แท็บเส้นทาง → "แก้เส้นทาง" เลือก **ปุ่ม 1 ครั้ง** หรือ **ปุ่ม 2 ครั้ง**
  → วาง / ลาก / ลบจุดบนระนาบ → กด **บันทึกลงหุ่น** (ไม่ทับเส้นทางหน้าเว็บ)
  - (0,0) = ที่หุ่นยืนตอนกดปุ่ม · +x = ทิศหน้าหุ่นตอนนั้น · +y = ซ้าย
  - เลือก **หน้าเว็บ** เพื่อกลับไปแก้เส้นทางของปุ่ม "เริ่มวิ่งหุ่นจริง" และการทดสอบ
  - ปุ่มที่มี " •" = ยังมีจุดที่แก้แต่ยังไม่บันทึก
- เดโม 3 / 4 วางเป้าจากทิศล้อจริงหลังหันเสร็จ จึงได้มุมเท่ากันทุกครั้ง: Direct ต้องหมุนล้อเกือบรอบ (~350°) ก่อนวิ่ง
  ส่วน Detour วิ่งไปก่อน แล้วค่อยหมุนน้อยกว่าและขยับข้างนิดเดียว
- ทุกเดโมจบที่จุดเริ่ม (วิ่งกลับเองหลังจุดสุดท้าย เดโม 3/4 ไม่นับเวลาขากลับ) จึงกดเดโมต่อได้ทันที
- เดโมที่เริ่มจากปุ่มไม่ต้องเปิดหน้าเว็บ (คนกดอยู่ข้างหุ่น ใช้ปุ่มหยุด) และหยุดเองถ้าเกิน 5 นาที
- เวลาของเดโม 3/4 ขึ้นในแท็บจำลอง ส่วน "ทดสอบเคลื่อนที่จริง" และแท็บเส้นทางแสดงสถานะปุ่มแบบสด
- เส้นทาง 1 ค่าเริ่มต้องมีพื้นที่ว่างประมาณ 1.3 × 1.3 ม. ไปทางหน้าและซ้ายของหุ่น
